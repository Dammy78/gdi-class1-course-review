# Practical training overview (MOD-07)

## Intent (summary)

MOD-07 is a **single continuous** on-road session combining instruction and evaluation. It includes:

- A **supported** phase for coaching and orientation  
- An **independent** phase with **minimum continuous independent driving** and **hazard commentary**  
- Pre-drive verification (licence, vehicle roadworthiness themes)  

Delivery must be conducted by personnel meeting **NZTA provider requirements** when the course is approved for delivery. **No one is authorised to deliver based on this public site alone.**

## Phases (learner view)

| Phase | Experience |
|-------|------------|
| Pre-drive | Briefing, checks, route overview at category level |
| Supported | Coaching permitted; builds toward independent driving |
| Independent | Independent driving; intervention for safety or compliance only |
| Debrief | Feedback and next steps (including supervised practice) |

## Competency domains (public overview)

Twelve practical competency areas (**PC-01–PC-12**) cover, in summary:

| PC | Domain (public summary) |
|----|-------------------------|
| PC-01 | Scanning and naming hazards in time |
| PC-02 | Speed/position adjustments to reduce risk |
| PC-03 | Observation at conflicts |
| PC-04 | Safe gap, yield, and priority choices |
| PC-05 | Speed suited to conditions and limits |
| PC-06 | Lane position and following margin |
| PC-07 | Predictable interaction with other road users |
| PC-08 | Smooth control; continuous independent driving |
| PC-09 | Commentary linking see → risk → action |
| PC-10 | Road rules and learner conditions |
| PC-11 | Pre-drive identity, licence, and vehicle checks |
| PC-12 | Safety — interventions and session integrity |

Provider scoring sheets and route-specific maps are **not** published here.

## Relationship to restricted practical test

This session **is not** the restricted practical test and **does not** predict test outcome. Continued supervised practice remains essential.
