# Learner workbook (formative — public review)

The workbook supports **formative** learning across MOD-01–06 and preparation for MOD-07. It is **not** a summative assessment and contains **no summative solutions**.

## Workbook parts (review-safe)

| Part | Purpose |
|------|---------|
| Orientation | How to use the workbook; draft status disclaimer |
| Module activities | Facilitated exercises aligned to modules |
| Formative checks | Low-stakes checks — distinct from summative theory |
| Practical preparation | Supervised practice guidance before MOD-07 |
| Reflection & action plan | Structured reflection and practice planning |
| Evidence record (learner) | Blank learner-side record templates |

## Not on this site

- Summative theory papers or item banks  
- Marking material or model responses  
- Provider-only practical evaluation forms
