# Class 1 learner licence course — public review

This site presents **read-only**, **review-safe** material for a Class 1 learner licence course design owned by **Danny Singh**. It is **separate from other GDI commercial training products** and is **not** an NZTA website.

## What this site is for

- Support **pre-submission review** before any NZTA course approval application.
- Help selected reviewers **navigate** course intent, structure, and learner-facing content.
- Remain **supplementary** to the formal controlled submission package.
